# 文案清单：定制前需要写什么

最省事的方法是先复制 `templates/character-profile.json`，把每个示例值换成自己的内容，再交给编程 AI。暂时想不到的项目可以保留中性默认文案。

## 1. 基础名称

至少准备以下内容：

| 项目 | 示例 | 出现位置 |
| --- | --- | --- |
| 角色名 | XX | 状态标题、提示和权限说明 |
| App 名称 | XX效率岛 | Finder、系统权限列表、打包文件名 |
| 菜单栏简称 | XX | 登录时启动等设置项 |
| Bundle ID | com.yourname.linxiaoman-island | macOS 识别不同 App 的唯一编号 |

Bundle ID 使用英文小写、数字、连字符或点，例如 `com.example.my-character-island`。制作不同角色时必须使用不同 Bundle ID，否则 macOS 可能把它们当作同一个 App。

## 2. 六种核心状态

每种状态写一个短标题和一句提示。标题尽量不超过 10 个中文字符，提示尽量不超过 32 个中文字符。

| 状态 | 标题示例 | 提示示例 |
| --- | --- | --- |
| 工作中 | XX工作中 | 当前任务已经开始，按节奏继续。 |
| 休息中 | 休息倒计时 | 先恢复状态，五分钟后再回来。 |
| 待命中 | XX待命中 | 暂时没有新任务，等下一步。 |
| 普通提醒 | XX提醒 | 提醒时间到了。 |
| AI 完成 | AI 任务完成 | 结果已经准备好，请先验收。 |
| 喝水 | 喝水时间 | 喝口水，调整一下状态。 |

还要写顶部常驻岛的短句，例如：

```text
工作：稳步推进 00:00 · EPM --
休息：休息中 05:00 · 不用着急
```

## 3. 四条默认提醒

模板默认包含：

```text
喝水｜每 2 小时
起身活动｜每 1 小时
午间校准｜12:00
下班｜19:00
```

需要为每条提醒准备：名称、默认时间和触发文案。时间既可以写固定时间 `16:30`，也可以写间隔 `每 30 分钟`、`每 2 小时`、`30min` 或 `1h`。

第一条默认为“喝水”，标题在面板中锁定；其余三条名称可以在面板中编辑。

## 4. 操作反馈

为了让角色语气完整，建议准备以下短句：

- 开始休息、提前结束休息、当前未在休息。
- 暂停计时、恢复计时、休息自然结束。
- 空闲 15 分钟提示。
- 喝水打卡成功。
- 恢复顶部小岛、重置小岛大小。
- 清零今日、清空全部、打开记录。
- 输入监控未授权、权限记录重置。
- Codex 完成、其他 AI 工具桥接完成。

没有写这些文案也能运行，编程 AI 可以先保留模板中的中性版本。

## 5. 角色语气建议

先用三到五个词定义角色，而不是只写“像某某”：

```text
性格：冷静、可靠、句子短、很少使用感叹号
称呼用户：你
催促强度：温和
避免：讽刺、制造焦虑、过度卖萌
```

这样不同 AI 更容易写出一致的状态文案，也更方便你检查。

## 6. 在代码里改哪里

编程 AI 应重点检查：

```text
Sources/CharacterEfficiencyIsland/main.swift
Packaging/Info.plist
build_app.sh
```

不要只改画面中的角色名；App 名、可执行文件名、Bundle ID、存储目录和资源 Bundle 名也需要一起处理。每次修改后都应运行 `./build_app.sh`。
