# 图片槽位：图片放哪里、怎样准备

所有运行图片都放在：

```text
Sources/CharacterEfficiencyIsland/Assets/
```

覆盖同名 PNG 即可，不需要修改文件引用。建议使用透明背景 PNG，并保留人物完整轮廓。

## 顶部小岛图片

| 文件名 | 用途 |
| --- | --- |
| `working.png` | 正常工作 |
| `break.png` | 休息倒计时 |
| `idle.png` | 30 分钟无活动后的待命状态 |
| `alert.png` | 普通提示和默认 AI 完成提示 |
| `ai.png` | 可选的专用 AI 完成图片 |
| `water.png` | 喝水提醒 |
| `reminder-second.png` | 第二条定时提醒 |
| `reminder-third.png` | 第三条定时提醒 |
| `reminder-fourth.png` | 第四条定时提醒 |
| `statusIcon.png` | macOS 菜单栏和 App 图标来源 |

推荐画布：800×800 或更大；人物四周保留约 5% 至 10% 透明空间。小岛图片会等比缩放，不要把人物贴死在画布边缘。

## 面板图的位置参数

每张面板图都可以单独调整。在 `main.swift` 搜索：

```swift
private func characterPlacement(for mode: CharacterMode)
```

每组参数含义：

```text
height   图片显示高度；越大人物越大
bottom   图片相对整个透明绘图区的底部距离；越大越往上
trailing 图片右侧距离；越小越往右，负数会继续向右伸出
```

模板初始值：

| 状态 | height | bottom | trailing |
| --- | ---: | ---: | ---: |
| 工作 | 310 | 72 | 42 |
| 休息 | 282 | 104 | 12 |
| 喝水 | 238 | 128 | -32 |
| 待命 | 330 | 52 | 42 |
| 第二提醒 | 310 | 72 | 42 |
| 第三提醒 | 232 | 150 | 42 |
| 第四提醒 | 310 | 64 | 42 |
| 普通/AI 提醒 | 230 | 150 | 42 |

不同 PNG 的透明边距差异很大，因此不要只比较图片文件尺寸。应运行 App，看人物实际可见轮廓，再微调三个参数。

## 对齐时怎样向 AI 描述

推荐使用明确的锚点：

```text
只向右平移，不改变大小，让人物最右端与面板右边框重合。
只向下平移，让椅子最低点与面板底边重合。
等比缩小，保持人物完整，让头顶不超过面板顶部横线。
腿和鱼竿可以伸出效率岛，但头部必须留在岛的上沿以内。
```

如果用截图画线，请说明“红线是当前点、蓝线是目标点”，并强调是只平移还是允许缩放。
